# KSHAN — AI Architecture & Integration Design

> **"AI proposes language; deterministic code owns math and reality."**

---

## 1. Principles

1. **Deterministic Core:** Gemini never touches mathematical allocations, currency splits, schedule dates, or task dependencies.
2. **Review Before Mutating:** Every AI output is delivered as an uncommitted candidate inside a `ReviewCard`. The host can Apply, Edit, or Dismiss.
3. **Honest Source Disclosure:** Every candidate displays an explicit source badge:
   - `<span class="badge">Suggested by Gemini (gemini-2.5-flash)</span>`
   - `<span class="badge">Generated by the built-in planner (Rule-based fallback)</span>`
4. **Anti-Prompt Injection Guardrails:** All untrusted user inputs are delimited inside `<USER_PROVIDED_DATA>...</USER_PROVIDED_DATA>` tags accompanied by strict system instructions forbidding instruction override.
5. **Ordered Model Failover:**
   - Primary: `gemini-2.5-flash`
   - Secondary: `gemini-1.5-flash`
   - Cooldown: 60-second backoff on 429 rate limit or quota exhaustion.
   - Offline fallback: Rule-based template generator producing grounded moments, estimates, and interview responses with 0 external network dependencies.

---

## 2. API Endpoints

All endpoints are hosted as Vercel serverless functions in `api/`:

| Endpoint | Method | Input | Output | Purpose |
|---|---|---|---|---|
| `/api/health` | GET | None | Diagnostic status JSON | Verifies model failover status, rate limiter, and fallback availability |
| `/api/interview` | POST | 5 host answers (vibe, guests, city, budget, priorities) | Structured celebration brief + 6-8 starter moments | Parses host narrative into actionable moments |
| `/api/ideas` | POST | Moment details + budget level | 3-tier moment ideas (modest, balanced, lavish) | Creative suggestions with realistic paise estimates |
| `/api/parse` | POST | Freeform celebration notes | Partial Event + Moments array | Extracts structured event details from raw unstructured notes |
| `/api/assistant` | POST | User prompt + current plan context | Grounded assistant advice | Answers questions about the host's specific plan without hallucinations |

## 3. Serverless Security Guard (`api/_shared.ts`)

Every API route runs through `handleApiPreflight`:
- **Method Enforcement:** Strictly allows specified HTTP method (`POST` or `GET`). Responds to `OPTIONS` with preflight `200 OK`.
- **Exact-Origin CORS:** Validates incoming `Origin` against production hosts and development localhost.
- **Body Size Cap:** Rejects requests $> 64\text{ KB}$ with `413 Payload Too Large`.
- **Per-IP Rate Limiting:** Sliding-window rate limiter restricting each client IP to 20 requests per minute.
- **Security Headers:**
  - `X-Content-Type-Options: nosniff`
  - `X-Frame-Options: DENY`
  - `Referrer-Policy: strict-origin-when-cross-origin`
  - `Strict-Transport-Security: max-age=63072000; includeSubDomains; preload`
