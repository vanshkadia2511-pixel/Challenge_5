# KSHAN video showcase assets

- `KSHAN_Project_Showcase_Pro.mp4`: full desktop product showcase.
- `KSHAN_LinkedIn_Teaser.mp4`: short highlight cut for LinkedIn.
- `KSHAN_Video_Thumbnail.png`: 1920x1080 cover image based on an actual frame from the supplied recording.
- `KSHAN_Captions.srt`: timed on-screen section captions (not a spoken-word transcript).
- `KSHAN_Chapters.txt`: section start times.

The edit keeps the supplied application footage and adds a branded intro/outro, chapter callouts, quick editorial cuts, subtle visual tuning and an original synthesized ambient soundtrack. The source recording's low-level audio was not carried through. No application source code was changed.
